    How it works

    1. Drop a file — preview instantly (image thumbnail, text snippet, CSV table). Magic bytes checked before any parse.
    2. Pick output — selector filters to compatible formats; explanation appears inline.
    3. Convert in RAM — multer.memoryStorage(), Sharp/PDFKit stream, Buffer → res.send() with Content-Disposition: attachment. No disk write.
    4. Download & gone — history logged to SQLite, file never persisted. Refresh shows Recent conversions.

    🔐 Security

    JWT hashed (SHA-256) in sessions, Helmet, CORS, rate-limit (100/15m, 20/15m auth), filename denylist, 10 MB cap, 25M pixel cap.

    ⚡ Performance

    In-process converters, no worker fork. Typical: MD→PDF ~25 ms, PNG→WebP ~11 ms, JSON→CSV ~5 ms (local).
